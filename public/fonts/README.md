# Noto Sans

Self-hosted variable Noto Sans (weights 100–900), from
`@fontsource-variable/noto-sans@5.3.0` on npm. These files are the Latin and
Latin Extended normal weight-axis subsets, renamed locally. Latin Extended
includes Turkish dotted uppercase İ, Ğ/ğ and Ş/ş; Latin includes dotless ı.

Source: https://www.npmjs.com/package/@fontsource-variable/noto-sans
Upstream: https://github.com/notofonts/latin-greek-cyrillic
License: SIL Open Font License 1.1; see `OFL-NotoSans.txt`.

The unicode ranges in `src/app/globals.css` match Fontsource's `wght.css`.
No runtime request to Google Fonts is required.
